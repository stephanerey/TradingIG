# Décisions

- Le mode relatif est le mode initial, avec stop `40` et objectif `80`.
- Pour un achat : stop = entrée − distance, objectif = entrée + distance.
- Pour une vente : stop = entrée + distance, objectif = entrée − distance.
- Les niveaux absolus résolus sont affichés et restent soumis aux validations existantes.
- Aucun réglage n'est persisté dans ce lot et aucun appel IG n'est ajouté.
- Ne pas engager de refonte visuelle dans ce lot ; les contrôles sont fonctionnels et provisoires.
