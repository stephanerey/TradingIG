# Décisions

- Les décimales sont persistées sous forme de chaînes exactes.
- Les poids doivent être positifs ou nuls et leur somme strictement positive.
- Les seuils respectent `0 <= Watch <= Candidate <= 100`.
- Un poids nul n'annule pas l'exigence de disponibilité d'une composante.
- L'héritage compte/stratégie/marché reste hors de cette tranche globale.
