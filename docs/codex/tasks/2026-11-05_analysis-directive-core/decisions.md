# Decisions

- La politique n'a aucun défaut caché : chaque consommateur doit fournir explicitement les états
  de consensus et risques acceptés ainsi que l'exigence IA.
- Une directive `READY` n'est pas un `OrderIntent` et ne contient ni compte ni quantité.
- Les preuves IA ne remplacent jamais les indicateurs ou les veto Scanner.
