# Constats

- Les stratégies, composantes et classements existaient déjà mais l'orchestration runtime ne
  traitait que l'instrument sélectionné dans la GUI.
- Le nouveau service réutilise les mêmes règles de fermeture, continuité, score et risque sans
  dupliquer leur logique.
- Le branchement GUI peut être différé sans bloquer la validation du cœur multi-marchés.
