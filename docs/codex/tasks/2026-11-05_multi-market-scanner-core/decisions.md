# Décisions

- Ordre d'évaluation stable par epic produit.
- Epic produit unique et identique à l'epic sélectionné de la série.
- Le contexte, le spread, les frais et la preuve d'échelle sont fournis explicitement par marché.
- Les poids/seuils globaux sont injectés ; aucune valeur favorable n'est inventée.
- Les erreurs de données deviennent des échecs locaux ; les erreurs de contrat du lot sont rejetées.
- Un profil doit activer au moins une stratégie et ne peut contenir de doublon.
- Le profil par défaut conserve exactement les paramètres preview existants.
