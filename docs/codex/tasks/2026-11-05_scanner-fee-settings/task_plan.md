# Frais manuels du Scanner

## Objectif

Ajouter dans Settings des frais estimés optionnels, par unité et par côté, puis alimenter le
composant Coûts sans supposer un tarif nul ni comparer des échelles de prix différentes.

## Autorité et limites

- Configuration globale validée par l'utilisateur le 2026-11-05.
- Types : CFD/DFB, Barrière, Option, Inconnu.
- Profil indicatif initial : CFD/DFB hors actions 0, Barrière 0,1, Option 0,1, Inconnu vide.
- Toute valeur peut être effacée ; vide = inconnu.
- Aucun ticket, ordre, appel externe ou activation LIVE/AUTO.
- Skill : `codex-tradingig-analysis-scanner`.
