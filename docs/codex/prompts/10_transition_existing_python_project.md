# Prompt Codex — transition d'un projet Python existant

Analyse le projet existant et prépare sa reprise contrôlée.

## Contraintes
- Ne modifie pas le code applicatif.
- Ne lance pas de refactor.
- Ne crée pas de dépendance.

## À faire
1. Lire `AGENTS.md` et `PROJECT_PROFILE.yaml`.
2. Générer `CODEBASE_MAP.generated.md`.
3. Identifier le layout Python : `src/`, package plat, scripts, tests.
4. Identifier les commandes de test/lint disponibles.
5. Compléter ou proposer une mise à jour de `docs/CURRENT_STATE.md`.
6. Proposer les skills métier utiles.
7. Lister les risques techniques.

## Sortie attendue
- cartographie courte ;
- commandes validables ;
- points risqués ;
- plan de transition en petites étapes.
