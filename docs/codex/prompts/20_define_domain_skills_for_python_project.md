# Prompt Codex — définir les skills métier d'un projet Python

À partir du code, des docs et du domaine, propose des skills métier Codex.

## Règles
- Ne pas inventer de règle métier.
- Distinguer skills Codex et agents runtime de l'application.
- Créer peu de skills, mais utiles et déclenchables.

## Sortie attendue
Pour chaque skill :

```text
name:
trigger:
scope:
risks:
references:
```

Ne génère les fichiers `SKILL.md` qu'après validation.
