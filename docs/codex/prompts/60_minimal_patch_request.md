# Prompt Codex — patch minimal

Traite la demande avec un patch minimal.

## Contraintes
- Travaille uniquement sur les fichiers nécessaires.
- Ne change pas l'architecture.
- Ne renomme rien sans nécessité prouvée.
- Ne reformate pas des fichiers entiers.
- Après modification, affiche le diff résumé et les tests à lancer.

## Format attendu
1. Plan court.
2. Fichiers lus.
3. Patch.
4. Vérification.
5. Risques restants.
