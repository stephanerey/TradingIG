# Prompt Codex — revue de diff avant clôture

Avant de terminer la tâche :

1. Exécute `python scripts/codex/safe_diff_summary.py`.
2. Vérifie les fichiers modifiés.
3. Vérifie l'absence de secrets.
4. Vérifie les imports et dépendances.
5. Vérifie les tests/lint exécutés ou documente l'impossibilité.
6. Mets à jour la mémoire de tâche.
7. Dis si `CURRENT_STATE.md` ou RepoMap doit être mis à jour.

Réponse finale courte : fait, fichiers modifiés, vérifications, risques restants.
